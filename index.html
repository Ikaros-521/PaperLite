常见问题（FAQ）

PaperLite 是什么？

PaperLite 是一款开源、本地优先的 LaTeX 论文编辑器，在浏览器里提供类似 Overleaf 的实时预览、TikZ 与表格可视化编辑，以及内置 XeLaTeX 真实编译，无需注册账号。

使用 PaperLite 需要安装 TeX 吗？

不需要。PaperLite 内置 XeLaTeX WebAssembly 引擎，首次编译会下载约 98 MB 的宏包与字体资源并缓存；也可以连接本机的 MiKTeX 或 TeX Live 获得完整发行版能力。

PaperLite 免费吗？

免费且开源，源码以 GPL-3.0-or-later 发布。AI 对话、AI 修复等功能需要自行配置兼容渠道的 API Key，费用由对应服务商收取。

文档会上传到服务器吗？

不会。文档默认保存在浏览器或你打开的本地文件夹中。只有主动使用文献检索、LanguageTool 语法检查、AI 对话等联网功能时，相关请求才会由浏览器直接发送到对应服务。

PaperLite 和 Overleaf 有什么区别？

PaperLite 无需账号、本地优先、开源，支持浏览器内真实编译和可视化图/表编辑；实时预览是论文常用子集的近似排版，复杂宏包、双栏分页与 bibtex 以编译出的 PDF 为准。PaperLite 不是 Overleaf 官方产品。

支持中文和手机吗？

支持。内置引擎可编译 ctexart 中文文档；手机访问站点路径加 #/m 即可使用移动版，复用同一套编辑器、编译与 AI 能力，草稿保存在当前浏览器。
